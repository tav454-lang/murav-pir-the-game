# Муравьиный пир v24.1

Откройте index.html в браузере. Для установки на iPhone разместите файлы в корне GitHub Pages, откройте сайт в Safari и выберите «Поделиться → На экран Домой».

Это HTML-игра, а не нативное iOS-приложение.

Компактные коробочки без рисунков муравьёв, открывающиеся крышки, новые материалы и палитра. Один муравей забирает один блок. Блок остаётся препятствием до фактического прибытия муравья. Выбор ближайшей незанятой доступной цели по длине маршрута. С 9-го уровня скрыты следующие отряды, одна отмена и одна подсказка.

Сохранены 624 уровня, музыка и ключ сохранения прогресса. Проверены суммы отрядов по цветам для каждого уровня, тесты резервирования, блокировки и ближайшей цели, запуск в браузере. Полная проходимость с новым выбором целей и производительность на настоящем iPhone требуют тестирования.

Публикация в репозитории не выполнена: подключение GitHub возвращает 403 при записи.

Коробочки в очереди и на сборе рисуются одной функцией, с одинаковыми размерами, материалом и числом. Различается только положение крышки. Круглые места заменены прямоугольными посадочными местами. На iPhone изменение ещё требует визуальной проверки.
